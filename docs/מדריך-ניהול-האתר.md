# מדריך ניהול האתר – טלרז תקשורת מתקדמת

המדריך הזה מסביר איך לעדכן את האתר **בלי שום ידע טכני**: לשנות טקסטים, להוסיף ולהסיר קבצים להורדה, לעדכן פרטי קשר ולפרסם את השינויים.

> שמרו את המדריך בהישג יד. כל פעולה כאן חוזרת על עצמה באותו אופן, ואין צורך לזכור הכול בעל פה.

---

## 1. מה זה האתר

- האתר נמצא בכתובת **https://tel-raz.com** (הכתובת tel-raz.co.il מפנה אליה אוטומטית).
- כל התוכן של האתר – טקסטים, תמונות וקבצים – נערך דרך **ממשק ניהול** פשוט שנראה כמו טפסים.
- כל שינוי שאתם שומרים נשמר בגיבוי מלא. **תמיד אפשר לחזור לגרסה קודמת**, כך שאין סיבה לחשוש לטעות.

### שלוש כתובות שכדאי לשמור כמועדפים (Bookmarks)

| מה | כתובת | למה |
|---|---|---|
| ממשק הניהול | https://tel-raz.com/admin/ | כאן עורכים את התוכן |
| תצוגה מקדימה | https://master--tel-raz.netlify.app | כאן רואים את השינויים לפני שהם עולים לאתר האמיתי |
| כפתור הפרסום | https://github.com/nitzanyiz/tel-raz/actions/workflows/publish.yml | כאן מפרסמים את השינויים לאתר האמיתי |

## 2. כניסה לממשק הניהול

1. היכנסו לכתובת **https://tel-raz.com/admin/**
2. לחצו על **Sign In with GitHub** (ממשק הניהול באנגלית, אבל כל השדות בעברית).
3. בפעם הראשונה GitHub יבקש לאשר גישה – לחצו **Authorize**.
4. מעכשיו הדפדפן יזכור אתכם, ולא תצטרכו להתחבר שוב בכל פעם.

> 📷 צילום מסך: מסך הכניסה לממשק הניהול

### מה רואים בממשק

בצד המסך מופיעה רשימת האזורים שאפשר לערוך:

| אזור | מה עורכים בו |
|---|---|
| **פרטי האתר** | טלפון, וואטסאפ, דוא"ל, כתובת, שעות פעילות, רשתות חברתיות, קישור להשתלטות מרחוק |
| **קבצים להורדה** | המדריכים והקבצים שמופיעים בעמוד "מדריכים" |
| **דף הבית** | הכותרת הראשית, כרטיסי השירותים, "למה טלרז", לוגואים של לקוחות |
| **שירותים ומוצרים** | ששת עמודי השירותים (iPECS Cloud, Panasonic וכו') |
| **עמודים** | עלינו, צור קשר, טופס קריאת שירות, מדריכים, עמוד התודה ועמוד "לא נמצא" |
| **מסמכים משפטיים** | הצהרת נגישות ומדיניות פרטיות |

> 📷 צילום מסך: הרשימה בצד המסך

## 3. איך שינוי מגיע לאתר: תצוגה מקדימה ← פרסום

זה העיקרון החשוב ביותר במדריך:

```
עורכים ושומרים בממשק  ──►  רואים בתצוגה המקדימה  ──►  לוחצים "פרסום"  ──►  האתר האמיתי מתעדכן
```

1. **שמירה (Save)** בממשק הניהול שומרת את השינוי ומעדכנת את **התצוגה המקדימה** תוך כדקה. האתר האמיתי **עדיין לא** משתנה.
2. פתחו את **התצוגה המקדימה** (https://master--tel-raz.netlify.app) ובדקו שהכול נראה טוב.
3. כשהכול מוכן – **מפרסמים**:
   1. היכנסו לכתובת כפתור הפרסום: https://github.com/nitzanyiz/tel-raz/actions/workflows/publish.yml
   2. לחצו על **Run workflow** (בצד ימין), ואז שוב על הכפתור הירוק **Run workflow**.
   3. אחרי כדקה–שתיים האתר האמיתי מתעדכן.

> 📷 צילום מסך: כפתור Run workflow

### למה לא מפרסמים כל שינוי מיד?

לאתר יש מכסה חודשית חינמית של כ-**15 פרסומים בחודש**. לכן:

- ✅ **עשו את כל השינויים, בדקו בתצוגה המקדימה, ופרסמו פעם אחת.**
- ❌ לא לפרסם אחרי כל תיקון קטן.
- שמירה בממשק הניהול ובדיקה בתצוגה המקדימה הן **ללא הגבלה** – רק הפרסום נספר.

## 4. משימות נפוצות

### 4.1 עריכת טקסט בעמוד

1. בממשק הניהול בחרו את האזור (למשל **שירותים ומוצרים**) ואת העמוד (למשל **מרכזיית Panasonic**).
2. ערכו את השדות: **כותרת העמוד**, **משפט פתיחה**, **תוכן העמוד**.
3. בשדה **תוכן העמוד** יש סרגל עיצוב פשוט: כותרות, הדגשה, רשימות וקישורים.
4. לחצו **Save**.

> טיפ: כותרות בתוך התוכן – השתמשו ב"Heading 2" לכותרת של פסקה. אל תשתמשו ב-"Heading 1", כי כותרת העמוד כבר קיימת.

### 4.2 הוספת קובץ להורדה (מדריך PDF, קובץ Word או Excel)

1. בממשק הניהול: **קבצים להורדה** ← **רשימת המדריכים והקבצים להורדה**.
2. לחצו על **Add קובץ** (הוספה) בתחתית הרשימה.
3. מלאו **כותרת** ו**תיאור קצר** (למשל: "עבור מרכזיות מסדרה NS500").
4. בשדה **קובץ** לחצו על בחירת קובץ והעלו את הקובץ מהמחשב.
5. לחצו **Save**.

> חשוב: תנו לקובץ שם ברור **לפני** ההעלאה (למשל "מדריך שינוי שם שלוחה.pdf"). אחרי שקובץ פורסם, **אל תשנו את שמו**, כי לקוחות עשויים להחזיק קישור ישיר אליו.

### 4.3 הסרת קובץ להורדה / שינוי הסדר

- **הסרה:** פתחו את הרשימה, לחצו על תפריט הפריט (⋮) ובחרו **Remove** (הסרה). שמרו.
- **שינוי סדר:** גררו פריט למעלה או למטה ברשימה. שמרו.

### 4.4 שינוי פרטי קשר

בממשק הניהול: **פרטי האתר** ← **פרטי האתר ויצירת קשר**.

| שדה | הסבר | דוגמה |
|---|---|---|
| טלפון (כפי שמוצג) | איך המספר נראה באתר | 09-7601760 |
| טלפון לחיוג | המספר בפורמט בינלאומי, בשביל לחיצה בנייד | ‎+97297601760 |
| מספר וואטסאפ | ספרות בלבד, מתחיל ב-972 ובלי ה-0 | 97297601760 |
| דוא"ל | | info@tel-raz.com |
| כתובת | מוצגת באתר וגם במפה בעמוד "צור קשר" | הרצל 1, רעננה |
| שעות פעילות | | א'–ה' 08:30–17:00 |
| רשתות חברתיות | קישור מלא לעמוד | https://facebook.com/... |
| קישור להשתלטות מרחוק | הכתובת שממנה לקוחות מורידים תוכנת השתלטות | |

> **שדה ריק = לא מוצג באתר.** למשל, אם תמחקו את מספר הוואטסאפ, הכפתור הירוק ייעלם. אם קישור ההשתלטות ריק, הפריט לא יופיע בתפריט.

### 4.5 עריכת דף הבית

בממשק הניהול: **דף הבית**. אפשר לשנות:

- הכותרת הראשית, משפט המשנה והטקסט של הכפתורים.
- **כרטיסי השירותים** – הכותרת והטקסט של כל כרטיס (הקישור של כל כרטיס קבוע).
- **"למה טלרז"** – הוספה, הסרה ועריכה של נקודות, ובחירת אייקון.
- **לוגואים של לקוחות** – האזור מוסתר כל עוד הרשימה ריקה. מוסיפים לקוח עם שם ולוגו, והאזור יופיע.

### 4.6 החלפת תמונה

1. בשדה התמונה לחצו על התמונה הקיימת (או על בחירת תמונה) והעלו תמונה חדשה.
2. **מלאו תמיד את "תיאור התמונה"** – זה טקסט קצר שמתאר מה רואים בתמונה (למשל "מרכזיית Panasonic NS500"). הוא חובה לפי חוק הנגישות.
3. שמרו.

> גודל מומלץ: עד 2MB. הממשק מקטין ומכווץ תמונות אוטומטית.

### 4.7 עריכת הצהרת הנגישות ומדיניות הפרטיות

בממשק הניהול: **מסמכים משפטיים**. מלאו את כל המקומות המסומנים **[למילוי]** והסירו את הסימון. בהצהרת הנגישות חובה לעדכן את **פרטי רכז/ת הנגישות** ואת **תאריך העדכון**.

## 5. כללים חשובים

1. **מפרסמים פעם אחת** בסוף כל סבב עריכה (כ-15 פרסומים בחודש זה בסדר גמור).
2. **תמיד בודקים בתצוגה המקדימה** לפני פרסום.
3. **תיאור לכל תמונה** – חובה לנגישות.
4. **לא משנים שם של קובץ** שכבר פורסם.
5. **לא כותבים "[למילוי]"** בטקסט שעולה לאתר – זה סימון בלבד.
6. הוספת עמודים חדשים ושינוי התפריט נעשים על ידי המפתח (ראו סעיף 7).

## 6. רשימת מילוי לפני השקה

הפריטים הבאים מסומנים כרגע **[למילוי]** וצריך למלא אותם לפני שהאתר עולה (שם הקובץ בסוגריים):

**פרטי האתר** (site)
- [ ] כתובת
- [ ] שעות פעילות
- [ ] רשתות חברתיות (אם יש)
- [ ] קישור להשתלטות מרחוק

**מסמכים משפטיים**
- [ ] הצהרת נגישות (accessibility): הסדרי נגישות במשרד, שם/טלפון/דוא"ל של רכז/ת הנגישות, תאריך עדכון
- [ ] מדיניות פרטיות (privacy): היכן נשמר המידע, שיתוף עם צדדים שלישיים, פרטי קשר לפרטיות, תאריך עדכון

**עמודים**
- [ ] עלינו (about): הסיפור של החברה

**שירותים ומוצרים** – להחליף את טקסט הדוגמה בתוכן אמיתי ולהוסיף תמונות:
- [ ] iPECS Cloud (ipecs-cloud)
- [ ] טלפוני IP מסדרה 1000i (ip-phones-1000i)
- [ ] מרכזיית Panasonic (panasonic) – כולל תיאור הדגם HT32
- [ ] מרכזיית Grandstream (grandstream)
- [ ] תמלול שיחות (call-transcription)
- [ ] מוקד קול סנטר (call-center)

**דף הבית** – לעבור על הכותרות והטקסטים ולוודא שהם מתאימים.

## 7. משהו השתבש?

- **שמרתי משהו לא נכון:** פשוט ערכו שוב ושמרו. אם עוד לא פרסמתם – האתר האמיתי לא נפגע.
- **פרסמתי משהו לא נכון:** תקנו בממשק, בדקו בתצוגה המקדימה ופרסמו שוב.
- **התצוגה המקדימה לא התעדכנה:** חכו 2–3 דקות ורעננו את הדף.
- **כפתור הפרסום נכשל (סימן X אדום):** אל תנסו שוב ושוב – פנו למפתח.
- **צריך עמוד חדש או שינוי בתפריט:** פנו למפתח.
- **כל דבר אחר:** פנו למפתח. כל שינוי שנעשה אי-פעם שמור, ותמיד אפשר לשחזר.
