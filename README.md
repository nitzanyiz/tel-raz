# tel-raz.com

Company website for **טלרז תקשורת מתקדמת**: a static Hebrew (RTL) site built with Eleventy, hosted on Netlify, and edited by a non-technical editor through Sveltia CMS at `/admin`.

```bash
npm install && npm start   # http://localhost:8080
npm test
```
